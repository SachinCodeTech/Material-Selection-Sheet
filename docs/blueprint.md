# **App Name**: ArchSpec Sheet

## Core Features:

- User Authentication: Secure user login, registration, and password recovery to protect project data.
- Project Management: Create, select, and delete projects. Each project contains multiple material selection sheets.
- Section Creation: Allows the user to create multiple sections within a project.
- Material Data Input: Interactive tables to input and edit material specifications, vendors, rates, and remarks for each section.
- Material Suggestions (AI): As users input material data, an AI tool suggests related materials and specifications based on common architectural practices and material compatibility.
- Data Persistence: Automatic saving of project data (projects, sections, materials data) in local storage.
- PDF Export: Generates shareable reports.

## Style Guidelines:

- Primary color: Teal (#045E7D) to convey professionalism and reliability, inspired by the architect's branding.
- Background color: Light grayish-blue (#F0F1F3), providing a clean, non-distracting backdrop to showcase material information.
- Accent color: Soft orange (#F3C900) for interactive elements and secondary actions. It is approximately 30 degrees to the "left" of teal, making it analogous, and its lower brightness and higher saturation provides a good contrast to the primary.
- Body and headline font: 'Inter' (sans-serif) for a modern, clean, and highly readable user interface.
- Crisp, line-based icons to represent actions and status, maintaining a minimalist aesthetic.
- A clean, modular layout with clear sectioning to organize material data effectively.
- Subtle transitions and animations to provide feedback on user interactions and maintain a dynamic feel.
